Gemini API key
Get a free key at aistudio.google.com/apikey. Stored only in this browser's local storage — it's sent directly to Google's API and nowhere else. Desktop notifications

Get a browser notification the moment a task comes due, while this tab is open. Browsers won't deliver notifications once the tab or computer is fully closed — the reminder will be waiting for you under Tasks and the bell icon next time you open Dealbook.
